Практична робота 3 — Форми та аудіо/відео
Розпакуйте архів і відкрийте index.html у браузері. Меню веде до всіх завдань і звіту report.html. Сервер та інтернет для сторінок не потрібні.
Медіа створені спеціально для демонстрації: шестисекундний тестовий ролик та три короткі синтезовані звукові тони. Це не музичні композиції.
Форми перевіряють введення локально; реєстрація й надсилання даних на сервер не виконуються.
Для здачі: перевірте роботу у чотирьох зазначених браузерах; імпортуйте Git bundle у свій репозиторій та надайте доступ викладачу. Не надсилайте реальні паролі через навчальні форми.
